# Regularization Analysis: Ridge vs. Lasso Regression

Project Title: Womens Clothing: Trends and Analysis in the Fashion Industry  
Task: Train a Lasso and Ridge Regression model and compare results by systematically tuning the regularization strength, assessing feature shrinkage effects, and visualizing coefficient distributions to understand model behavior.  
Environment: Jupyter Notebook  


## Overview

This analysis investigates regularized linear models (L2 Ridge and L1 Lasso Regression) to predict clothing review ratings (`Rating`) using numerical and behavioral predictors (`Age`, `Recommended IND`, and `Positive Feedback Count`). 

## Data Preprocessing & Scaling

1. Target & Feature Definition:
   * Target (y): `Rating` (Scale: 1 to 5)
   * Features (X): `Age`, `Recommended IND`, `Positive Feedback Count`
2. Train/Test Splitting:**
   * 80% Training set, 20% Evaluation hold-out set (`random_state=42`).
3. Standardization:
   * Fitted with `StandardScaler` to bring features onto a zero-mean  and unit-variance  scale.
   * Rationale: Regularization penalties are scale-sensitive; unscaled features with larger numeric variance would disproportionately dominate penalty calculations.


##  Regularization Analysis Workflow

### 1. Systematic Hyperparameter (alpha) Tuning
* Tested different Alpha values: 0.001, 0.01, 0.1, 1, 10, and 100 for both Ridge and Lasso    models.
* Compared their R² scores to see how different Alpha values affect model performance and to find the best value.

### 2. Feature Shrinkage Profiles
* Ridge (L2 Penalty): Reduces the coefficient values as Alpha increases. Coefficients get closer to zero but usually do not become exactly zero.
* Lasso (L1 Penalty): Reduces coefficient values as Alpha increases. Some coefficients can become zero, which helps identify less important features.

### 3. Model Evaluation & Comparison
Ridge and Lasso models are compared using three evaluation metrics:
* MAE (Mean Absolute Error): Measures the average difference between actual and predicted ratings.
* RMSE (Root Mean Squared Error): Measures prediction errors and gives more importance to larger errors.
* R^2 Score: Shows how well the model predicts the ratings. A higher score indicates better performance.
